# Hi, I’m Kumar Aditya

## Building Folio

[**Folio**](https://github.com/Kumar-Aditya3/Folio) is an open-source, local-first book and manga reader for Android and Windows. Bring your own books, keep your reading progress and saved passages on your device, and make the reader feel like your own.

[Download the Android preview](https://github.com/Kumar-Aditya3/Folio/releases/tag/v1.2.131) · [Download the Windows preview](https://github.com/Kumar-Aditya3/Folio/releases/tag/windows-v1.0.38) · [Explore the code](https://github.com/Kumar-Aditya3/Folio) · [Report a problem or suggest an idea](https://github.com/Kumar-Aditya3/Folio/issues/new/choose)

Built with Kotlin Multiplatform and Compose Multiplatform. Features include adjustable typography, highlights and notes, reading activity, optional on-device semantic search, and Android offline narration with downloadable voice packs. The portable Windows preview includes its Java runtime.
